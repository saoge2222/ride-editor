# GUI图形化组件

你是一名精通Rust的前端软件工程师.

该前端依赖为Zed GPUI渲染框架,需要你自己完成各个图形组件的定义.文件在`/crates/gui/gui-widgets`内.

## 文件输出约定

- 不要输出任何注释
- 只允许在规定文件内和项目根目录修改Cargo.toml,build.rs,否则需要向用户请求
- 所有组件在`crates/gui/gui-widgets/src`文件夹下按照不同组件类型分开文件夹储存.
- 若在Build模式下读入数据,不要立即输出,需向用户确认
- 输出Plan时使用中文

## 涉及组件内容

1. 按钮
    - 基础属性
        - ID名(用于后端通讯识别事件)
        - 按钮长宽,边框颜色,,内部填充文字
        - 按钮内置文本
        - 文本字体
        - 文本字号
        - 按钮SVG图标
            - 图标长宽
        - 按钮事件处理:以下事件处理
            - 是否被点击
            - 是否有鼠标悬停
        - 按钮后端通讯输入输出
        - 按钮内多内容排布(同时排列文字,图标等要素的排版)

2. 列表:一个由若干个按钮自上而下而排列的一个组件集合
    - 基础属性
        - ID名
        - 列表组件后端输入输出(接收Git文件状态,LSP服务器返回)
        - 各按钮的管理,将后端输入处理转发到每一个按钮上

3. 树:一个带有层级的,自上而下的按钮组件集合
    - 基础属性
        - ID名
        - 按钮之间的层级关系(可以内置,可以通过端口获得各个层级间的关系)
        - 每一级与上一级的缩进像素数
        - 缩进对齐线显示(默认不显示)
        - 树组件后端输入输出(接收Git文件状态,LSP服务器返回)
        - 各按钮的管理,将后端输入处理转发到每一个按钮上

4. 文本框:非编辑器区域输入文本的区域
    - 基础属性
        - ID名
        - 文本框长宽,填充颜色,边框颜色
        - 文本框上部/下部/左侧/右侧的标题文字(穿过边框线),及其字号,字体 
        - 文本框内输入文字字体,字号
        - 文本框所占文字行数
        - 文本框占位符(占位文字,在输入行内的图标)
        - 事件处理:
            - 是否有鼠标悬停
            - 是否有文字在文本框内
        - 后端通讯:将文本打包输出,以及必要的输入接口

5. 编辑器区域:输入代码区域
    - 基础属性
        - ID名
        - 文字字体(强制使用等宽字体)及文字大小
        - 行号区域:
            - 行号统一右侧对齐,留足9位数字空间,外加一列空区域
            - 空区域安插占位符,用于插入断点
            - 行号右侧留出一小列空间(一条细线的空间)安插Git添加,修改,删除的标记
            - 行号与输入文字区域
        - 编辑器区域: 文本需要和行号完全对齐,需要实现为文本添加波浪号
        - 底部状态栏: 接收根据LSP服务器回传信息而分析而得的文档层级(如当前所处的函数,结构体等)
        - 后端数据接入: LSP服务接口(用于标识代码出现的问题,分析代码结构,辅助跳转),语法树解析返回(与LSP配合,用于文本高亮)
        - 输出模块: 向文件管理系统输出写入文件与内容

### 组件编译时出现的问题:

1. 多行文本框无法自动换行
2. 代码块行号系统排布错误,应为如下:
```
+-----------------------------------------------------------+
|   断点符号,应为圆形         行号(右侧对齐)    Git状态提示 |
+-----------------------------------------------------------+
```
3. (准备添加的feature)标签栏: 代码编辑器窗口标签页栏
