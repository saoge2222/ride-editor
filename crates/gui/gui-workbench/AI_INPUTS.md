# Ride Editor 图形界面布局

你是一名精通Rust的GUI前端设计师.

图形界面渲染依赖Zed GPUI,组件模版依赖`crates/gui/gui-widgets`,编译前需要向Cargo.toml添加依赖.

## 要求
- 仅使用基于Zed GPUI进行渲染的组件库组件进行渲染
- 各窗口需要支持异步渲染,当窗口不被显示的时候终止渲染进程,实现性能优化.

## 各窗口说明
**所有内容均需为英语**
- 菜单栏: 从左到右显示按钮"文件""编辑""选择""视图""跳转""工具""帮助",各个按钮靠左侧对齐
- 工具栏:所有按钮均为图标在上,文字在下且文字字脚均朝向右侧,工具栏宽度接近文字高度.
    - 左工具栏:从上到下分别为"文件管理器""书签""运行与调试""Git管理"
    - 右工具栏:从上到下分别为"终端""输出""文档符号""问题"
    - 图标现在暂时使用方块代替
- 状态栏:
    - 最左侧显示从项目根目录开始当前编辑的文件位置以及所处的函数/字段等文本要素的位置(具体显示暂时略)
    - 最右侧从左到右为:文件位置(格式:`Col:Row`),文件编码,文件换行方式(CRLF/LF),制表符等价空格显示,目前文档高亮语言方式,后台通知(先用空心方块代替)
- 编辑器区域:
    - 支持窗口水平/垂直分割,分割后等分编辑器区域
    - 每一个窗口最顶部为标签页标签,(已在`gui-widgets`完成定义)
    - 窗口余下部分为编辑器区域(已在`gui-widgets`完成定义)
